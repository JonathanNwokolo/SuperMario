# Super Mario

Este projeto é uma recriação simples do jogo Super Mario usando HTML, CSS e JavaScript.

## Estrutura do Projeto
- `index.html`: Página principal do jogo.
- `style.css`: Estilos para o layout e visual do jogo.
- `script.js`: Lógica e funcionalidades do jogo.
- `img/`: Pasta com imagens utilizadas no jogo.

## Como executar
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em seu navegador.

## Funcionalidades
- Controle do personagem Mario.


Projeto desenvolvido para fins educacionais.
